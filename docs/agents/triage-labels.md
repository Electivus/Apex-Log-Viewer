# Triage Labels

The skills speak in terms of five canonical triage roles. This file maps those roles to the team-scoped Linear labels used by the `Electivus` team.

| Label in mattpocock/skills | Label in our tracker | Meaning                                  |
| -------------------------- | -------------------- | ---------------------------------------- |
| `needs-triage`             | `needs-triage`       | Maintainer needs to evaluate this issue  |
| `needs-info`               | `needs-info`         | Waiting on reporter for more information |
| `ready-for-agent`          | `ready-for-agent`    | Fully specified, ready for an AFK agent  |
| `ready-for-human`          | `ready-for-human`    | Requires human implementation            |
| `wontfix`                  | `wontfix`            | Will not be actioned                     |

When a skill mentions a role (for example, "apply the AFK-ready triage label"), use the corresponding Linear label from this table.

Resolve labels by exact name in team `Electivus`. Create a missing label as a team-scoped label only when a workflow needs to apply it.
